# Security Policy

## Reporting a Vulnerability

Navis Marine Services Ltd takes the security of its website and infrastructure seriously. If you discover a security vulnerability, please disclose it responsibly.

**Do not open a public issue or pull request.** Instead, report it privately to:

- **Email:** info@navismarineservicesltd.com

Please include:

- A description of the vulnerability and the affected component/endpoint.
- Steps to reproduce (if applicable).
- Impact assessment (what an attacker could achieve).
- Suggested mitigation (optional).

## Response

We will acknowledge receipt within 5 business days and work to triage, fix, and release a remediation. We ask that you refrain from disclosing the vulnerability publicly until we have released a fix.

## Supported Versions

Only the latest production deployment (the `main` branch / Vercel production deployment) is actively supported. Deployments from the `test` branch are for review and CI purposes only.
